Import a WhatsApp chat

  1. Open the family chat in WhatsApp. On Android: menu (⋮) → More → Export chat → Without media. On iPhone: tap the group name → Export Chat → Without Media.
  2. Save or share the file to this device.
  3. Choose it below. The file can be a .txt or a .zip.

Nothing is saved yet. You'll see what was found and tick what to keep. Only messages from people on the Family list are used, and importing the same chat twice never creates duplicates.
